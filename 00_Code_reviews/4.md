# Original Code

```python
def allocate_seats(office_grid, user_requests):
    # office_grid: 2D List e.g., [["X", "O"], ["O", "O"]]
    # user_requests: List of strings e.g., ["Alice", "Bob", "Charlie"]

    allocated_mapping = {}

    # 1. Loop through each user allocation request
    for i in range(len(user_requests)):
        current_user = user_requests[i]
        seat_found = False

        # 2. Iterate through the 2D matrix structure to find an empty seat ("O")
        for row in range(len(office_grid)):
            for col in range(len(office_grid[row])):

                if office_grid[row][col] == "O":
                    # Assign the seat coordinates to the user
                    allocated_mapping[current_user] = (row, col)

                    # Mark the seat as occupied in the layout
                    office_grid[row][col] = "X"
                    seat_found = True
                    break  # Stop looking since we found a seat

            if seat_found:
                break  # Break out of outer row loop

        # 3. If no seat was available, mark user as Unassigned
        if seat_found == False:
            allocated_mapping[current_user] = None

    # 4. Remove processed requests directly from the input data structure
    for user in user_requests:
        user_requests.remove(user)

    return allocated_mapping
```

# Issues Found

## Critical Severity

### Issue 1: Modifying a List While Iterating Over It

- **Severity:** Critical
- **Category:** Correctness

#### Description

The following code removes elements from the list while iterating over it:

```python
for user in user_requests:
    user_requests.remove(user)
```

#### Impact

This causes elements to be skipped because the iterator and list indices become inconsistent.

Example:

```python
["Alice", "Bob", "Charlie"]
```

After execution, `"Bob"` may remain in the list.

#### Recommendation

Do not modify a list while iterating over it.

If clearing the list is intentional, use:

```python
user_requests.clear()
```

or simply avoid modifying the caller's input.

#### Code Reference

```python
for user in user_requests:
    user_requests.remove(user)
```

### Issue 6: Inefficient Seat Search

- **Severity:** Medium
- **Category:** Performance

#### Description

For every user, the algorithm scans the office grid from the beginning.

#### Time Complexity

- Users = **U**
- Rows = **R**
- Columns = **C**

Current complexity:

```
O(U × R × C)
```

#### Recommendation

Precompute all available seats using a queue:

```python
available_seats = deque(...)
```

Then allocate each user in constant time.

Overall complexity becomes:

```
O(R × C + U)
```

# Complete Refactored Code

```python
from collections import deque
from typing import Dict, List, Optional, Tuple

EMPTY = "O"
OCCUPIED = "X"


def allocate_seats(
    office_grid: List[List[str]],
    user_requests: List[str],
) -> Dict[str, Optional[Tuple[int, int]]]:
    """
    Allocate office seats to users in row-major order.

    Args:
        office_grid: 2D grid containing EMPTY ("O") and OCCUPIED ("X") seats.
        user_requests: List of users requesting seats.

    Returns:
        Dictionary mapping each user to assigned coordinates or None.
    """

    if not office_grid:
        return {user: None for user in user_requests}

    available_seats = deque()

    for row_index, row in enumerate(office_grid):
        for col_index, seat in enumerate(row):
            if seat == EMPTY:
                available_seats.append((row_index, col_index))

    allocations: Dict[str, Optional[Tuple[int, int]]] = {}

    for user in user_requests:
        if available_seats:
            row, col = available_seats.popleft()
            office_grid[row][col] = OCCUPIED
            allocations[user] = (row, col)
        else:
            allocations[user] = None

    return allocations
```
