# JavaScript Code Review Example

## Problem Statement

Return **false** if any number is negative.

Return **true** if any number is more than 500.

Return **true** if total is more than 1000.

---

# Original Code

```javascript
const nums = [100, -50, 500];

function myFunction(nums) {

    var negativeNum = false;
    var moreThan500 = false;
    var total = 0;

    for (i = 0; i < nums.length; i++) {

        if (nums[i] < 0) {
            negativeNum = true;
        }

        if (nums[i] >= 500) {
            moreThan500 = true;
        }

        total += nums[i];
    }

    if (negativeNum == true)
        return false;

    if (moreThan500)
        return true;

    if (total > 1000)
        return true;
}
```

---

# Review Findings

## 1. Correctness

### Issues

- No null or undefined validation for `nums`.
- No validation that `nums` is actually an array.
- No validation that array contains only numbers.
- Empty array behavior is undefined.
- Condition says **more than 500**, but code checks:

```javascript
nums[i] >= 500
```

Should be

```javascript
nums[i] > 500
```

- Function has no default return value. If none of the conditions match, it returns `undefined`.

### Recommendation

- Validate input.
- Validate array elements.
- Add explicit `return false`.

---

## 2. Error Handling

### Issues

No exception handling.

Possible runtime errors:

- `nums` is null
- `nums` is undefined
- `nums` is a string
- Array contains objects

### Recommendation

Throw meaningful exception or return validation error.

---

## 3. Performance

### Positives

Only one pass through the array.

Complexity

- Time : **O(n)**
- Space : **O(1)**

### Improvements

Return immediately when a negative number is found.

Current implementation unnecessarily scans the remaining array.

---

## 4. Maintainability

### Issues

Function performs

- Validation
- Business logic

Variable names can be improved.

`myFunction()` is not descriptive.

### Recommendation

Rename to

```javascript
evaluateNumbers()
```

# Revised Code

```javascript
/**
 * Evaluates an array of numbers.
 *
 * Rules:
 * 1. Return false if any number is negative.
 * 2. Return true if any number is greater than 500.
 * 3. Return true if total is greater than 1000.
 * 4. Otherwise return false.
 */

function evaluateNumbers(nums) {

    if (!Array.isArray(nums)) {
        throw new TypeError("Input must be an array.");
    }

    if (nums.length === 0) {
        return false;
    }

    let total = 0;

    for (const num of nums) {

        if (typeof num !== "number") {
            throw new TypeError("Array must contain only numbers.");
        }

        if (num < 0) {
            return false;
        }

        if (num > 500) {
            return true;
        }

        total += num;
    }

    return total > 1000;
}
```

---

# Alternative Modern JavaScript Solution

```javascript
function evaluateNumbers(nums) {

    if (!Array.isArray(nums)) {
        throw new TypeError("Input must be an array.");
    }

    if (nums.some(num => typeof num !== "number")) {
        throw new TypeError("Array contains invalid values.");
    }

    if (nums.some(num => num < 0)) {
        return false;
    }

    if (nums.some(num => num > 500)) {
        return true;
    }

    const total = nums.reduce(
        (sum, num) => sum + num,
        0
    );

    return total > 1000;
}
```
